SMC-PAD Controller Bindings Documentation

To be able to use this script you have to import supplied device preset using MidiSuite.

Documentation needs update !!!

This document describes control bindings for the script operating in following modes:

  • Production
  • Perform
  • Device manipulation

Overview

The script operates using modes, banks, and a shift modifier.

  • Modes redefine the behavior of all controls.
  • Banks allow reuse of knobs and faders.
  • Shift enables secondary functions.
Shift Modifier: Pad 24 (Note 71) acts as a global Shift button. Shifted behavior is documented explicitly in all tables.
